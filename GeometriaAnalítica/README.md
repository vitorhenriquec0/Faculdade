# Geometria Analítica e Vetores (GAV)

Neste repositório coloco alguns códigos realizados na disciplica GAV na UNESP (Universidade Estadual Paulista) de S. J. do Rio Preto.
Para tais exercícios propostos durante o andamento da displicina, foi utilizada a linguagem Python e a biblioteca Numpy, que é uma biblioteca
 para a linguagem de programação Python, que suporta o processamento de grandes, multi-dimensionais arranjos e matrizes, juntamente com uma 
grande coleção de funções matemáticas de alto nível para operar sobre estas matrizes.

Durante o semestre trabalhamos com conteitos de matrizes, plano e espaço, vetores, projeção ortogonal, ortonormalização de bases, seções cônicas, produto vetorial e muito mais.
Tais conhecimentos foram aplicados diretamente e indiretamente nestes projetos.
